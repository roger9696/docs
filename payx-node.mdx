title: "PayX Node SDK"
description: "Server-side integration for Node.js"
---

The `payx-node` SDK provides a robust set of tools for interacting with the PayX API from your server-side Node.js applications. It handles authentication, request signing, response parsing, and error management automatically.

## Installation

Install the package via NPM:

```bash
npm install payx-node@latest
```

## Initialization

Initialize the client with your **v2 Secret Key** retrieved from the [PayX Dashboard](https://payx.company/dashboard).

```javascript
const { PayX } = require('payx-node');

const payx = new PayX({
  apiKey: 'px_live_v2_6ba7b810-9dad-11d1-80b4-00c04fd430c8'
});
```

## 1. Creating Checkout Sessions (Inline Checkout)

Generate a short-lived (30-minute) scoped token for client-side checkout with `payx-js`:

```javascript
const checkout = await payx.checkout.create({
  amount: 100.00,
  currency: 'GHS',
  email: 'user@example.com'
});

console.log('Scoped Checkout Token:', checkout.checkoutToken);
console.log('Hosted Checkout URL:', checkout.url);
```

Pass `checkout.checkoutToken` to your frontend to render `PayX.checkout({ token: checkout.checkoutToken })`.

## 2. Direct Collections (Mobile Money Charge)

To initiate a direct USSD prompt on a customer's phone, use `charge.create`:

```javascript
const charge = await payx.charge.create({
  amount: 50.00,
  currency: 'GHS',
  phoneNumber: '0551234567',
  network: 'MTN',
  payerMessage: 'Order #1234'
});

console.log('Transaction ID:', charge.transactionId);
console.log('Status:', charge.status); // PENDING
```

---

## 3. Payouts (Disbursements)

Send money to any mobile money wallet using `payouts.create`. 

<Note>
  `payouts.create` requires an `idempotencyKey` (16–128 alphanumeric characters, hyphens, and underscores) to prevent duplicate payouts during network retries.
</Note>

```javascript
const payout = await payx.payouts.create({
  amount: 250.00,
  currency: 'GHS',
  phoneNumber: '0241234567',
  network: 'MTN',
  idempotencyKey: '9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d',
  payeeNote: 'Vendor Disbursement'
});

console.log('Payout Transaction ID:', payout.transactionId);
console.log('Payout Status:', payout.status);
```

## 4. Webhook Verification

Verify that incoming webhooks are authentic and signed with your webhook secret (`whsec_live_...` or `whsec_test_...`):

```javascript
// Express.js Webhook Route
app.post('/api/webhooks', (req, res) => {
  const signature = req.headers['x-payx-signature'];
  const webhookSecret = process.env.PAYX_WEBHOOK_SECRET; // whsec_live_...

  const isValid = payx.webhooks.verifySignature(
    req.body,
    signature,
    webhookSecret
  );

  if (!isValid) {
    return res.status(401).json({ error: 'Invalid signature' });
  }

  const { event, data } = req.body;
  if (event === 'transaction.success') {
    console.log('Transaction succeeded:', data.id);
  }

  res.status(200).send('OK');
});
```
