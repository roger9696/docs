---
title: "Create Payout"
api: "POST /payout"
description: "Send money to a mobile wallet"
---

Disburse funds directly to a mobile money wallet (MTN, Telecel, AirtelTigo).

### Headers

<ParamField header="Idempotency-Key" type="string" required>
  A unique identifier (16–128 characters consisting of letters, numbers, hyphens, or underscores) to prevent duplicate transactions if a network timeout or retry occurs.
</ParamField>

<ParamField header="x-api-key" type="string" required>
  Your Secret API Key (`px_live_v2_...` or `px_test_v2_...`). Alternatively, you can use the `Authorization: Bearer <key>` header.
</ParamField>

---

### Body Parameters

<ParamField body="amount" type="number" required>
  The amount to send in GHS. Must be a positive number with at most 2 decimal places (e.g. `250.00`).
</ParamField>

<ParamField body="phoneNumber" type="string" required>
  The recipient's 10-digit mobile money number (e.g., `0241234567`).
</ParamField>

<ParamField body="network" type="string" required>
  The network provider. Supported values: `MTN`, `TELECEL`, `AIRTELTIGO`.
</ParamField>

<ParamField body="currency" type="string" default="GHS">
  The currency code. Currently only `GHS` is supported.
</ParamField>

<ParamField body="payeeNote" type="string">
  A note that will appear in the recipient's transaction history.
</ParamField>

<ParamField body="payerMessage" type="string">
  A note for the merchant's internal records.
</ParamField>

<ParamField body="email" type="string">
  Optional email address of the recipient.
</ParamField>

<ParamField body="metadata" type="object">
  Custom JSON data to associate with the payout.
</ParamField>

---

### Response

<ResponseField name="message" type="string">
  A summary of the initiation status.
</ResponseField>

<ResponseField name="transactionId" type="string">
  The unique transaction identifier for status checks and reconciliation.
</ResponseField>

<ResponseField name="status" type="string">
  The initial status of the payout (e.g., `PENDING` or `PROCESSING`).
</ResponseField>

---

<RequestExample>

```bash curl
curl -X POST https://payx.company/api/v1/payout \
  -H "x-api-key: px_live_v2_YOUR_SECRET_KEY" \
  -H "Idempotency-Key: sample-unique-idempotency-key-12345" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 250.00,
    "phoneNumber": "0241234567",
    "network": "MTN",
    "payeeNote": "Supplier Payment"
  }'
```

```javascript Node.js
const { PayX } = require('payx-node');
const payx = new PayX({ apiKey: process.env.PAYX_SECRET_KEY });

const res = await payx.payouts.create({
  amount: 250.00,
  currency: 'GHS',
  phoneNumber: '0241234567',
  network: 'MTN',
  idempotencyKey: 'sample-unique-idempotency-key-12345',
  payeeNote: 'Supplier Payment'
});

console.log('Payout ID:', res.transactionId);
```

</RequestExample>

<ResponseExample>

```json 202 Accepted
{

```

</ResponseExample>
